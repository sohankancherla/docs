## [Components](https://react.dev/learn/your-first-component)

Components are reusable JSX code that can be used to build a UI.

<CodeGroup>
  ```tsx {1, 7} App.tsx

  export default function MyApp() {

      </div>
    );
  }
  ```

  export function MyButton() {

## Displaying Data

Use curly braces `{}` to display data in JSX.

```jsx {7}
const user = {
  name: 'John'
};

return (
  <h1>
    {user.name}
  </h1>
);
```


## Conditional Rendering

Use `if` statements or logical operators to conditionally render components.

### If Statement

```jsx {2-6}
let content;
if (isLoggedIn) {
  content = <AdminPanel />;
} else {
  content = <LoginForm />;
}

return (
  <div>
    {content}
  </div>
);
```

### Logical Operators

```jsx {3-6}
return (
  <div>
    {isLoggedIn ? <AdminPanel /> : <LoginForm />} // Ternary Operator
    {isLoggedIn && <LogoutButton />} // Logical AND
    {user.name || "Anonymous"} // Logical OR
    {price ?? "Cart is empty"} // Logical OR with nullish coalescing (preserves zero and empty strings)
  </div>
);
```


## Rendering Lists

Use the `map()` function to render a list of items.
<Warning>When rendering a list, always include a unique `key` prop usually the `id` of the item. Do not use the index of the item as the key unless the list will never change between renders.</Warning>

```jsx {9-11}
const users = [
    {id: 1, name: 'John'},
    {id: 2, name: 'Jane'},
    {id: 3, name: 'Doe'}
]

return (
  <ul>
    {users.map((user) => (
      <li key={user.id}>{user.name}</li>
    ))}
  </ul>
);
```

## Event Handlers

You can respond to events by declaring event handler functions inside your components.

```jsx {2-4, 7}
function MyButton() {
  function handleClick() {
    alert('You clicked me!');
  }

  return (
    <button onClick={handleClick}>
      Click me
    </button>
  );
}
```


## Props

### Passing Props

You can pass data from a parent component into a child component using props

```jsx {4,5}
export default function Profile() {
  return (
    <Avatar
      person={{ name: 'Donald Trump', imageId: '1bX5QH6' }}
      size={100}
    />
  );
}
```

### Reading Props

Destructure the props to use them in your component. Remember to use Typescript to keep your code type safe.

```jsx {9}
interface AvatarProps {
    person: {
        name: string;
        imageId: string;
    },
    size?: number;
  }

export default function Avatar({ person, size = 100 }: AvatarProps) {
  // ...
}
```

### Forwarding Props

You can forward props to a child component using the `...` spread operator.

```jsx {11}
interface ProfileProps {
  person: {
      name: string;
      imageId: string;
  },
  size?: number;
}

function Profile(props: ProfileProps) {
  return (
    <Avatar {...props} />
  );
}
```

### Children

You can pass children to a component using the `children` prop.

```jsx {5, 8}
interface CardProps {
    children: ReactNode;
}

function Card({ children }: CardProps) {
  return (
    <div className="card">
      {children}
    </div>
  );
}

export default function Profile() {
  return (
    <Card>
      <Avatar
        person={{ name: 'Donald Trump', imageId: '1bX5QH6' }}
        size={100}
      />
    </Card>
  );
}
```
