## [Imports and Exports](https://react.dev/learn/importing-and-exporting-components)

### Exporting

Export components, types, functions, or variables using the `export` keyword.
<Note>For better code maintainability, prefer using named exports. Use default exports only when explicitly needed (e.g. Next.js pages)</Note>

<CodeGroup>
```tsx Profile.tsx
export default function ProfilePage() {
  // ...
}
```

```tsx avatar.tsx
export function Avatar() {
  // ...
}
```
</CodeGroup>

### Importing

Import components, types, functions, or variables using the `import` keyword.

```tsx
import { Avatar } from "./avatar.tsx";
```

<Tip>You can rename the imported component using the `as` keyword. This only works with named exports.</Tip>

```tsx
import { Avatar as AvatarComponent } from "./avatar.tsx";
```


## [Displaying Data](https://react.dev/learn/javascript-in-jsx-with-curly-braces)

Use curly braces `{}` to display data in JSX.

```jsx {7}
const user = {
  name: 'John'
};

return (
  <h1>
    {user.name}
  </h1>
);
```


## [Conditional Rendering](https://react.dev/learn/conditional-rendering)

Use `if` statements or logical operators to conditionally render components.

### If Statement

<Tip>Prefer conditionally assigning JSX to a variable for clean and easy to maintain code.</Tip>

```jsx {2-6}
let content;
if (isLoggedIn) {
  content = <AdminPanel />;
} else {
  content = <LoginForm />;
}

return (
  <div>
    {content}
  </div>
);
```

### Logical Operators

<Warning>Don't put numbers on the left side of `&&`. A common mistake is to write code like `messageCount && <p>New messages</p>` which renders `0` when messageCount is `0`. Instead, make the left side a boolean expression: `messageCount > 0`</Warning>

```jsx {3-6}
return (
  <div>
    {isLoggedIn ? <AdminPanel /> : <LoginForm />} // Ternary Operator
    {isLoggedIn && <LogoutButton />} // Logical AND
    {user.name || "Anonymous"} // Logical OR
    {price ?? "Cart is empty"} // Logical OR with nullish coalescing (preserves zero and empty strings)
  </div>
);
```


## [Rendering Lists](https://react.dev/learn/rendering-lists)

<Warning>When rendering a list with `map()`, always include a unique `key` prop usually the `id` of the item. Do not use the index of the item as the key unless the list will never change between renders.</Warning>

### Map

Use the `map()` function to render a list of items.

```jsx {9-11}
const users = [
  {id: 1, name: 'John'},
  {id: 2, name: 'Jane'},
  {id: 3, name: 'Doe'}
]

return (
  <ul>
    {users.map(user => 
      <li key={user.id}>{user.name}</li>
    )}
  </ul>
);
```

### Filter

use the `filter()` function to render a list of items that match a condition.

```jsx {7-9}
const users = [
  {id: 1, name: 'John', isAdmin: true},
  {id: 2, name: 'Jane', isAdmin: true},
  {id: 3, name: 'Doe', isAdmin: false}
]

const admins = users.filter(user => 
  user.isAdmin
);

return (
  <ul>
    {admins.map(user =>
      <li key={user.id}>{user.name}</li>
    )}
  </ul>
);
```

## [Props](https://react.dev/learn/passing-props-to-a-component)

### Passing Props

You can pass data from a parent component into a child component using props

```jsx {4,5}
export default function Profile() {
  return (
    <Avatar
      person={{ name: 'Donald Trump', imageId: '1bX5QH6' }}
      size={100}
    />
  );
}
```

### Reading Props

Destructure the props to use them in your component. Remember to use Typescript to keep your code type safe.

```jsx {9}
interface AvatarProps {
    person: {
        name: string;
        imageId: string;
    },
    size?: number;
  }

export default function Avatar({ person, size = 100 }: AvatarProps) {
  // ...
}
```

### Forwarding Props

You can forward props to a child component using the `...` spread operator.

```jsx {11}
interface ProfileProps {
  person: {
      name: string;
      imageId: string;
  },
  size?: number;
}

function Profile(props: ProfileProps) {
  return (
    <Avatar {...props} />
  );
}
```

### Children

You can pass children to a component using the `children` prop.

```jsx {5, 8}
interface CardProps {
    children: ReactNode;
}

function Card({ children }: CardProps) {
  return (
    <div className="card">
      {children}
    </div>
  );
}

export default function Profile() {
  return (
    <Card>
      <Avatar
        person={{ name: 'Donald Trump', imageId: '1bX5QH6' }}
        size={100}
      />
    </Card>
  );
}
```
